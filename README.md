# 速算反应训练

心算速度 · 数字大脑反应力训练网页应用。纯原生 HTML / CSS / JavaScript 实现，零依赖、零构建，打开即玩。

## 玩法

- **限时挑战**：60 / 120 / 180 秒，时间到自动结算
- **固定题数**：20 / 50 题，答完即结算

### 题目规则

| 题型 | 范围 | 占比 |
| --- | --- | --- |
| 加法 | 两个 3~4 位数（100–9999）相加 | 35% |
| 减法 | 两个 3~4 位数相减，结果非负 | 35% |
| 乘法 | 两位数 × 两位数（10–99） | 22% |
| 除法 | 被除数 ≤4 位、除数 ≤2 位，保证整除 | 8% |

### 计分

- 答对得 **100 分**基础分
- **5 秒内**答完按速度加分，每快 1 秒 +10
- **连击** 3 题起，每题额外 +10 × 连击数（封顶 ×5）
- 答错显示正确答案后自动进入下一题

## 功能

- 结果页：得分、正确率、平均/最快反应、最高连击、分题型表现、错题回顾
- 历史记录：localStorage 本地持久化（上限 200 场），薄弱题型分析
- 深色模式自适应、移动端适配、动效降级（prefers-reduced-motion）

## 本地运行

直接用浏览器打开 `index.html` 即可，或起一个静态服务：

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 目录结构

```
├── index.html   # 页面结构（首页 / 答题 / 结果 / 历史）
├── style.css    # 样式
└── app.js       # 题目生成、计分、会话流程、存储与渲染
```
